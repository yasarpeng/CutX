# CutX Icon Generation Prompts

## Product Context
- **Name**: CutX
- **Type**: Cross-platform offline file splitter & merger CLI tool
- **Tagline**: One binary, three platforms, offline, split & merge 100GB files like puzzle pieces
- **Palette**: Deep dark background (#0a0e14), blue accent (#5eb1ff), green success (#4cd964)
- **Target**: Windows GUI application icon (.ico)

## Candidates (8 directions)

1. Scissors cutting a file block — literal "cut" metaphor
2. File split into puzzle pieces reassembling — "like puzzle" tagline
3. Arrow splitting into two diverging arrows — split/merge duality
4. Stack of layered file blocks — chunk visualization
5. Hexagonal tile splitting into fragments — geometric/technical
6. Blade/split line through a document — clean minimal cut
7. Two interlocking halves forming a whole — merge concept
8. Abstract "X" formed by split arrows — CutX brand mark
