# CutX 功能清单 (Feature List) — V3.0

## 模块1：文件切割 (Split)

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| S-01 | 基本切割 | 指定源文件和切割大小，流式切割为分片 | 🔴 P0 | 默认2G，支持G/M/K |
| S-02 | 清单文件生成 | 自动生成JSON清单，含元数据+hash | 🔴 P0 | |
| S-03 | 单遍hash计算 | 在同一遍读取中计算per-chunk hash和overall hash | 🔴 P0 | 零额外I/O |
| S-04 | 进度显示 | 实时进度+ETA | 🔴 P0 | ETA基于已用时间推算 |
| S-05 | 自定义输出目录 | -o 参数指定输出目录 | 🟡 P1 | |
| S-06 | 4位序号命名 | part0001~part9999 | 🔴 P0 | 上限9999个分片 |
| S-07 | 残留分片清理 | split前删除{源文件名}.part*和.manifest.json | 🔴 P0 | 不误删其他文件 |
| S-08 | --hash参数 | 选择md5(默认)/sha256 | 🔴 P0 | 仅split接受 |
| S-09 | FAT32检测 | FAT32+分片≥4GB时报错中止 | 🔴 P0 | |
| S-10 | 符号链接跟随 | 读取实际文件，分片用链接文件名 | 🔴 P0 | |
| S-11 | 合并命令提示 | 完成后输出verify和merge命令提示 | 🟡 P1 | |
| S-12 | 断点续切 | 中断后跳过已完成分片 | 🟢 P2 | V1.1 |

## 模块2：文件合并 (Merge)

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| M-01 | quick模式合并 | 纯I/O合并，不计算hash | 🔴 P0 | 默认模式 |
| M-02 | verify模式合并 | 边写边校验+后校验 | 🔴 P0 | --mode verify |
| M-03 | 预检 | 检查分片存在、大小、磁盘空间 | 🔴 P0 | 所有模式共享 |
| M-04 | 输出文件覆盖保护 | 默认拒绝覆盖，--force可覆盖 | 🔴 P0 | |
| M-05 | 进度显示 | 按字节数计算进度 | 🔴 P0 | |
| M-06 | verify模式删除输出 | 校验失败时删除输出文件 | 🔴 P0 | |
| M-07 | 后校验 | verify模式比对overall hash | 🔴 P0 | 失败保留文件，退出码2 |
| M-08 | 自定义输出路径 | -o 参数 | 🟡 P1 | |
| M-09 | 断点续合并 | 中断后跳过已写入部分 | 🟢 P2 | V1.1 |

## 模块3：完整性校验 (Verify)

| 功能编号 | 功能名称 | 功能描述 | 优先级 | 备注 |
|---------|---------|---------|--------|------|
| V-01 | 分片校验 | 逐个分片计算hash与清单比对 | 🔴 P0 | |
| V-02 | 清单完整性检查 | 验证JSON、必填字段、数组一致性 | 🔴 P0 | |
| V-03 | 分片缺失检测 | 报出缺失分片列表 | 🔴 P0 | |
| V-04 | 分片大小检查 | 检查每个分片大小与清单一致 | 🔴 P0 | |
| V-05 | 算法自动识别 | 从清单读取hash_algorithm | 🔴 P0 | |

|---------|---------|---------|--------|------|

| C-09 | --mode参数 | quick(默认)/verify | 🔴 P0 | 仅merge |
| C-10 | --force参数 | 强制覆盖输出文件 | 🔴 P0 | 仅merge |
| C-11 | --quiet参数 | 安静模式 | 🟢 P2 | |
