Core Features

核心功能

文件切割 split

流式读取大文件，按指定大小切分。默认 2GB 每片，支持自定义大小。自动生成清单文件和分片校验和。

文件合并 merge

读取清单文件，逐片校验 SHA-256 后流式合并。预检磁盘空间，边写边校验，确保合并成功。

完整性校验 verify

不执行合并，仅校验所有分片的 SHA-256。快速排查传输过程中损坏的分片，定位需重传的文件。

Delivery Workflow

交付工作流

1

交付方：切割大文件

在有网络的源环境中，使用 cutx split 将 100GB 文件切割为 50 个 2GB 分片，自动输出到 cutx-ubuntu-server/ 子目录

$ cutx split ubuntu-server.img -s 2G
2

传输到客户环境

将 cutx 二进制 + cutx-ubuntu-server/ 子目录（含 50 个分片 + 清单），通过 U 盘或局域网传入离线环境

3

客户方：校验分片

合并前先校验所有分片完整性，确保传输无损

$ cutx verify cutx-ubuntu-server/ubuntu-server.img.manifest.json
4

客户方：合并还原

校验通过后，合并所有分片还原为原始 100GB 文件

$ cutx merge cutx-ubuntu-server/ubuntu-server.img.manifest.json

Quick Start

快速开始

三步开始使用 CutX

1

下载二进制文件

选择对应平台的二进制文件，放到 PATH 目录即可使用

# macOS / Linux
$ chmod +x cutx && sudo mv cutx /usr/local/bin/
2

切割文件

将大文件切割为指定大小的分片

$ cutx split ubuntu-server.img -s 2G
3

合并还原

在目标环境中合并分片，还原原始文件（输入 cutx-ubuntu-server/ 子目录中的清单文件）

$ cutx merge cutx-ubuntu-server/ubuntu-server.img.manifest.json
